# 电子束直写剂量综合台

纯前端（TypeScript + React）的电子束直写剂量综合工具：在浏览器本地编辑或导入整数剂量图与允许孔径，
**完整比较所有可行击发多重集**，给出唯一最优、并列最优（展示字典序最小的前两份规范方案）或不可实现的判定，
并可逐次查看每次击发、累计剂量与剩余剂量。全部计算在本地完成，不发出任何业务网络请求。

## 问题模型

- 剂量图：2–5 行 × 2–6 列，每格目标剂量为 0–4 的整数，总剂量 ≤ 36。
- 允许孔径：1–8 种矩形，宽、高为正整数且不得越过剂量图边界。
- 一次击发：选定孔径矩形的一个零基放置 `(top, left, height, width)`，使其覆盖的每格剂量恰 +1；允许重复击发；任何时刻不得过曝。
- 最优性准则：先最小化击发次数；并列时对每份方案按 `(top, left, height, width)` 元组升序排列后取整份列表的字典序。
- 求解器：按规范序为全部可行放置编号，以带记忆化的递归枚举每种放置的使用次数（每个多重集恰好枚举一次），
  返回最少击发次数、最优多重集数量（区分唯一/并列）及字典序最小的前两份方案。任何输入改动都会立即撤下旧结论。

## 本地开发

```bash
npm ci            # 安装依赖
npm run dev       # 开发服务器
npm run test:run  # 单元测试（含与暴力枚举对拍的随机测试）
npm run build     # 类型检查 + 产出静态站点 dist/
npm run preview   # 本地预览构建产物
```

## 导入格式

JSON 对象，`apertures` 支持 `{ "height": h, "width": w }` 或 `[h, w]` 两种写法：

```json
{
  "rows": 2,
  "cols": 2,
  "cells": [[1, 1], [1, 1]],
  "apertures": [{ "height": 1, "width": 2 }, [2, 1]]
}
```

## Docker 交付

```bash
# 构建并启动静态站点（宿主机端口可配置，默认 8080）
HOST_PORT=9000 docker compose up -d web

# 一次性验证：代码测试 + 构建检查 + HTTP 冒烟，结束后自行退出并以退出码报告结果
docker compose up --build --exit-code-from verify verify
echo $?   # 0 表示全部通过
```

- `web` 服务：多阶段构建的 Nginx 静态站点，内置 `/healthz` 健康检查，Compose 健康检查就绪后才放行验证。
- `verify` 服务：依次执行单元测试（`vitest run`）、构建检查（`tsc --noEmit && vite build`）、
  对 `web` 的首页/构建产物/健康端点做 HTTP 冒烟，随后自行退出并以退出码报告结果。
